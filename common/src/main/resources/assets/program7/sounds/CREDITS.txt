IMPLEMENTATION NOTES
====================

Format Requirements:
- All .ogg files must be valid Ogg Vorbis audio format
- Non-looping sounds should use "stream": false
- Looping sounds (rotor, engine, tracks, etc.) should use "stream": true
- Loop sounds should be designed for seamless looping

Directory Structure:
- All .ogg files belong in: common/src/main/resources/assets/program7/sounds/
- Organized by category: entity/, unit/, block/, event/ subdirectories (optional)
- Filenames must exactly match what sounds.json references (minus .ogg extension)

Verification:
- After downloading, verify each file with: file <path> (should show Ogg/Vorbis)
- Test loop sounds in-game for seamless playback
- Manager/maintainer must verify CC0/PD licensing before commit to CurseForge

VERIFICATION CHECKLIST
